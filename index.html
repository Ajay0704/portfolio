How I work · shown on the E-commerce build

From the question to a number you can defend.

  1. 01  Start from the questions

    Every dashboard starts with what each team actually asks. For Olist that meant five teams, so five report pages, one per stakeholder.

  2. 02  Model the data once

    A pandas pipeline turns 9 raw tables into a 7-table star schema with key checks, so every KPI is defined in one place.

  3. 03  Build the dashboard as code

    62 DAX measures written as code, and page titles that state the answer instead of just naming the chart.

  4. 04  Check every number

    An independent pandas check matched 30 of 30 DAX results, and caught a BLANK = 0 bug that showed 4.21★ instead of 4.29★.

About

Between the data and the decision.

I started on a garment-factory floor in Tirupur, where production counts were written on paper and a late report meant a missed shipment window. I spent my first months on the floor before touching the data, and that habit stuck.

I moved to Boston for a master’s in business analytics. What shaped how I think wasn’t the coursework; it was the work outside it. Organisations trying to figure out if what they were doing actually made a difference. Stakeholders who knew something was off but couldn’t name it.
